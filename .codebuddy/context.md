# 觅食图小程序 - 项目上下文文档

## 项目概述
**项目路径**: `F:\美食地图APP\觅食图-小程序`  
**技术栈**: 微信小程序 + JavaScript  
**功能**: 美食/景点推荐、地图导航、收藏想去、数据筛选

---

## 项目结构

```
觅食图-小程序/
├── pages/
│   ├── index/          # 首页 - 美食列表+地图
│   ├── spots/          # 景点列表页
│   ├── articles/       # 文章推荐页
│   ├── my/             # 个人中心
│   └── ...

│   ├── shopData.js     # 店铺基础数据（蛇口24家）

│   ├── markerIcons.js  # 地图标记图标
│   ├── util.js         # 工具函数
│   └── ...
├── app.js              # 应用入口
└── app.json            # 应用配置
```

## 核心页面配置

### 首页 (pages/index/index.js)
- **默认城市**: 深圳
- **数据来源**: `shopData.shops` + `shopData.foods` + 用户添加
- **筛选维度**: 城市 → 区域 → 分类 → 排序
- **地图**: 腾讯地图，支持定位

### 景点页面 (pages/spots/spots.js)
- **默认城市**: 深圳
- **数据来源**: `spotData.js`
- **筛选维度**: 城市 → 区域 → 分类
- **想去功能**: localStorage存储

## 继续开发注意事项

### 数据更新流程
1. Excel数据位于: `F:\美食地图APP\城市数据收集\{城市名}\`
2. 使用Python脚本转换Excel为JSON格式
3. 更新 `foodData.js` 和 `spotData.js`
4. 检查 `shopData.js` 的 `foods` 字段引用

### 调试技巧
- 首页添加了 `[Index]` 前缀的console日志
- 可在微信开发者工具控制台查看数据加载流程
- 检查 `applyFilters()` 函数确认筛选逻辑

### 常见问题
- **页面空白**: 检查控制台日志，确认 `loadShops()` 是否被调用
- **地图不显示**: 检查 `mapCenter` 和 `markers` 数据
- **数据为空**: 检查 `shopData.js` 的 `foods` 引用是否正确

---

## 代码风格
- 使用 `module.exports` 导出数据
- 城市名称不含"市"后缀 (如 "深圳" 而非 "深圳市")
- 区域名称与 `districtMap` 配置精确匹配
- 标记图标使用40x40彩色圆点
