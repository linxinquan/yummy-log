# 觅食图 / Me Tour

> 深圳·蛇口美食探店路线规划小程序

以蛇口为起点，逐步覆盖深圳、广州等广东城市的美食与景点探索。

## 功能特性

- 🗺️ **探索地图** — 微信原生地图，分类展示美食与景点，支持距离筛选和城市切换
- ❤️ **想去清单** — 收藏美食与景点，按城市/已规划/未规划筛选，城际路线规划
- 🗺️ **路线规划** — 多日行程编排，地点拖拽排序，支持文字/链接导入解析
- 📸 **采集打卡** — 拍照记录地点，AI 生成打卡内容，追踪探索足迹
- 👣 **足迹地图** — 已打卡地点的地图展示与统计概览
- 📝 **攻略** — 城市/区县精选攻略卡片，内置深圳各区攻略
- 🤖 **AI 描述生成** — 智能生成地点描述文案
- 📍 **多地图导航** — 高德、百度、腾讯、苹果地图一键跳转
- 🔗 **攻略导入** — 粘贴小红书/微信公众号正文或链接，智能识别地点并生成路线

## 技术栈

- 微信小程序原生框架
- 微信原生地图组件
- 微信云开发（CloudBase）
- localStorage 数据持久化
- Open-Meteo 天气 API
- MingCute 图标库
- 设计 Token 系统（CSS 变量）

## 数据说明

- **地点数据**: 内置深圳/广州等城市的美食与景点数据
- **用户数据**: 想去清单、路线、打卡记录存储在 localStorage
- **攻略数据**: 内置深圳各区攻略 + 用户创建攻略
- **封面图**: COS 云存储 + 默认封面图池兜底
