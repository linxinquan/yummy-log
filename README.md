# 🍜 觅食图 / Me Tour

> 深圳·蛇口美食探店路线规划小程序

觅食图是一款以**美食探店**和**旅行路线规划**为核心的微信小程序，从深圳蛇口出发，逐步覆盖广东主要城市。帮助美食爱好者和旅行者发现、收藏、规划并记录每一次美食探索之旅。

## ✨ 功能特性

### 🗺️ 探索地图
- 微信原生地图，分类展示**美食**与**景点**
- 按分类、评分、距离智能筛选
- 支持深圳、广州、汕头、佛山、珠海等城市切换
- 热门美食标签快捷过滤（肠粉、糖水、烧腊等）
- 当前位置定位与城市区划自动识别

### ❤️ 想去清单
- 一键收藏感兴趣的美食与景点
- 按城市、已规划/未规划筛选
- 想去人数热门排行展示
- 滑动删除管理想去地点

### 🗺️ 路线规划
- 多日行程自由编排，支持天数选择（1-10天）
- 地点拖拽排序，灵活调整行程顺序
- 地点间交通方式与距离估算
- 行程概览卡片，清晰展示每日安排
- 智能推荐路线，贪心最近邻算法优化

### 📝 攻略导入
- 粘贴小红书、微信公众号等平台的链接或正文
- 智能文本解析，自动识别地点名称
- 一键生成带坐标的路线规划
- 内置深圳各区精选攻略（福田、南山、罗湖等）

### 📸 采集打卡
- 拍照记录美食与景点
- AI 智能生成打卡描述文案
- 地址选点与地图定位
- 探索足迹自动统计

### 👣 足迹地图
- 已打卡地点地图分布展示
- 打卡数量、地点总数等统计卡片
- 快速添加足迹入口

### 🤖 AI 描述生成
- 一键生成地点打卡文案
- 智能识别地点特色，自动生成推荐语

### 📍 多地图导航
- 支持高德地图、百度地图、腾讯地图、苹果地图一键跳转导航
- 路线概览预览，出行更便捷

## 🚀 快速开始

### 前置条件

- 微信开发者工具（最新版）
- 微信小程序 AppID：`wxd63e0f59de062cd9`

### 运行步骤

1. 克隆项目到本地
   ```bash
   git clone https://github.com/zweioio/route-planning.git
   ```
2. 打开微信开发者工具，点击「导入项目」
3. 选择项目目录，填入 AppID
4. 点击「编译」即可预览

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| 微信小程序原生框架 | 页面与组件开发 |
| 微信原生地图组件 | Map、Marker、POI 检索 |
| 微信云开发 (CloudBase) | 数据存储与云函数 |
| localStorage | 用户数据持久化 |
| Open-Meteo API | 天气信息获取 |
| MingCute Icons | 图标库 |
| CSS 设计 Token 系统 | 全局色板、间距、圆角统一管理 |

## 💾 数据说明

- **内置数据**: 深圳、广州、汕头、佛山、珠海等城市的美食与景点数据
- **用户数据**: 想去清单、路线规划、打卡记录存储在微信本地缓存
- **攻略数据**: 内置深圳各区精选攻略 + 用户自定义攻略
- **封面图片**: 腾讯云 COS 对象存储 + 默认封面图池兜底
- **天气数据**: 基于当前定位调用 Open-Meteo 天气接口
