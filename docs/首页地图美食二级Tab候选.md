# 首页地图美食二级 Tab 候选

## 目的

- 给首页地图一级分类中的`美食`补充二级 Tab 候选。
- 当前先只覆盖 5 个常用城市：`深圳`、`广州`、`汕头`、`佛山`、`珠海`。
- 每个城市先保留 4 个主打美食类型，后续可继续增删调整。

## 交互规则

- 只有点击一级分类`美食`时，才显示二级 Tab。
- 二级 Tab 显示在一级分类 Tab 下方。
- 二级 Tab 不单独放`全部`。
- 二级 Tab 第一项固定放当前城市的第一个主打美食。
- 切换城市后，二级 Tab 跟着切换成该城市对应的美食类型。
- 不同城市之间允许出现重复美食类型，比如`肠粉`可以同时出现在深圳和广州。
