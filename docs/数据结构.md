# 地点数据结构

| 字段              | 类型           | 说明                                      | 示例                                              |
| --------------- | ------------ | --------------------------------------- | ----------------------------------------------- |
| id              | number       | 唯一编号                                    | `100`                                           |
| name            | string       | 地点名称                                    | `大佛寺`                                           |
| type            | string       | 地点或美食 `spot` \|` food`                  | `spot`                                          |
| displayCategory | string       | 展示分类                                    | `景点`                                            |
| subCategory     | string       | 二级分类，如 `自然景点` `文化展馆` `饮品` `购物中心` `酒店` 等 | `文化展馆`                                          |
| city            | string       | 所在城市                                    | `广州`                                            |
| district        | string       | 所在区                                     | `天河`                                            |
| address         | string       | 详细地址                                    | `天河区惠福东路惠新中街21号`                                |
| lat             | number       | 纬度                                      | `23.122373`                                     |
| lng             | number       | 经度                                      | `113.268027`                                    |
| location        | GeoJSON      | `{ type, coordinates: [lng, lat] }`     | `{"type":"Point","coordinates":[113.26,23.12]}` |
| desc            | string       | 简介文字：一句话突出亮点，有画面感，适合社交媒体展示                   | `夜晚亮灯后金碧辉煌...`                                  |
| tags            | string[]     | 标签列表：3-6个简短特色标签，用于筛选和展示                    | `["闹市禅意","古风大片"]`                               |
| coverImage      | string       | 封面图 URL                                 | `https://...`                                   |
| openHours       | string       | 营业时间，空=未知                               | `""`                                            |
| free            | boolean      | 是否免费                                    | `false`                                         |
| avgPrice        | number\|null | 人均价格，`null`=暂无均价                        | `null`                                          |
| rating          | number       | 评分 0–5                                  | `4.78`                                          |
| checkInCount    | number       | 打卡人数                                    | `0`                                             |
| wantCount       | number       | 想去人数                                    | `0`                                             |
| createdAt       | string       | 创建时间 ISO 8601                           | `2026-05-12T09:46:19.872Z`                      |
| updatedAt       | string       | 更新时间 ISO 8601                           | `2026-05-12T09:46:19.872Z`                      |

## 示例

```json
{
  "id": 100,
  "name": "大佛寺",
  "type": "spot",
  "displayCategory": "景点",
  "subCategory": "文化展馆",
  "city": "广州",
  "district": "天河",

  "desc": "夜晚亮灯后金碧辉煌，广州最具梦幻感的夜景地标。",
  "tags": ["闹市禅意", "6米铜佛", "古风大片"],
  "coverImage": "https://example.com/dafo.jpg",
  "openHours": "",
  "free": false,
  "avgPrice": null,
  "rating": 4.78,
  "checkInCount": 0,
  "wantCount": 0,
  "createdAt": "2026-05-12T09:46:19.872Z",
  "updatedAt": "2026-05-12T09:46:19.872Z"
}
```
